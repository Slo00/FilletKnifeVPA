# ADR-001: источник метрик для рекомендателя

## Статус
Принято, 14.09.2026

## Контекст
Штатный рекомендатор берёт замеры из metrics-server (~15 мин в памяти).
Недостаточно для оценки профиля потребления; после maintenance рекомендации
падают до минимума и поды не стартуют.

## Решение
Источником выступает внешнее хранилище (VictoriaMetrics), опрашиваемое
на каждом цикле, а не однократно при старте.

## Последствия
Появляется внешняя зависимость: недоступность хранилища должна
приводить к сохранению прежних значений, а не к их пересчёту.
Отпадает необходимость в чекпоинтах и прогреве после рестарта.
